# 🚀 CODYSSEY

> A structured coding journey through the world of **C** – from basics to advanced concepts

This repository contains code examples, exercises, and small educational projects for learning C step by step. Each chapter focuses on a specific topic, and the code is provided with explanatory comments.

## 📂 Repository Structure

| # | Folder | Topic |
|---|--------|-------|
| 01 | [01-Fundamentals](./01-Fundamentals) | Basics – variables, data types, operators, I/O |
| 02 | [02-Conditional Statements](./02-Conditional%20Statements) | Conditional statements – if, else if, switch, ternary operator |
| 03 | [03-Loops](./03-Loops) | Loops – for, while, do-while, nested loops |
| 04 | [04-Random Number](./04-Random%20Number) | Random numbers – rand(), srand() and random distributions |
| 05 | [05-Function](./05-Function) | Functions – definition, call, parameters, overloading |
| 06 | [06-Template](./06-Template) | Templates – function templates, class templates |
| 07 | [07-Cmath](./07-Cmath) | Math library – sqrt, pow, sin, cos, etc. |
| 08 | [08-Array](./08-Array) | Arrays – 1D, 2D, character arrays |
| 09 | [09-STL](./09-STL) | Standard Template Library – vector, map, set, algorithm, iterator |
| 10 | [10-String](./10-String) | Strings – C strings, character arrays, string functions |
| 11 | [11-File](./11-File) | Files – reading/writing text and binary files |
| 12 | [12-Pointer](./12-Pointer) | Pointers – pointers, references, dynamic memory |
| 13 | [13-UDT](./13-UDT) | User-Defined Types – struct, class, enum, union |
| 14 | [14-Time](./14-Time) 

## ⚙️ Prerequisites

- C11 or higher compiler (GCC, Clang, MSVC)
- Basic command-line knowledge
- (Optional) VS Code with C/C++ extension

## 🧪 How to Run

```bash
# Navigate to any chapter folder
cd 05-Function

# Compile (example with gcc)
gcc main.c -o output

# Run
./output
```
